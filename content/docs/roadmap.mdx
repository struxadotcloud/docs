title: Roadmap
description: Planned features and known limitations for Struxa.
---

## What's Working

- Server management - create, start, stop, restart, delete
- Real-time console streaming over WebSocket
- File manager with upload, download, edit, and delete
- Node management and Wings node registration
- Eggs and Nests (Pterodactyl-compatible server templates)
- Cron-based schedule automation (power actions, commands, backups)
- Backup management - local and S3-compatible
- Database management for game servers
- Admin console for users, nodes, nests, and eggs

## Planned

- **Multi-user RBAC** - sub-user permissions scoped per server
- **API key management** - per-user API keys for external integrations
- **Email notifications** - alerts for server events and admin actions
- **VPS provisioning** - create and attach cloud nodes from the panel
- **Billing module** - built-in billing system for hosting operators, with plan management and invoicing
- **Two-factor authentication** - TOTP support in the panel UI
- **Mobile-friendly UI** - responsive layout improvements
