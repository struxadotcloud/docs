---
title: Wallet & Payments
description: How the wallet works — topping up, transaction history, and referrals.
---

Every user has a wallet: a prepaid balance used to pay for plans and renewals. It's funded through a payment provider, and the balance updates automatically when the provider confirms a payment.

## Topping up

On `/billing/wallet`, users click **Top Up**, pick a provider, and choose an amount — a preset or any custom value. Payment happens on the provider's own checkout page, and the wallet is credited as soon as the provider's webhook arrives. Every top-up shows up in the transaction history.

Admins can also credit or debit a wallet directly from the user's page (**Admin → Users → [user]**) — handy for manual payments or refunds.

## Referrals

Turn referrals on under **Admin → Billing → Settings** and set the two percentages: a bonus for the new user and a commission for the referrer.

Each user gets a personal referral code (**Wallet → Referrals**). When a new user applies it before their first top-up, both sides earn: the new user gets a bonus on top of what they paid, and the referrer gets a commission based on that first top-up.

The details:

- the code must be applied before the first top-up, and both credits land when that top-up completes
- bonuses apply to the first top-up only
- your own code is for sharing with new users — you apply a code from someone else
- each account can apply exactly one code
- each code keeps a total usage count
